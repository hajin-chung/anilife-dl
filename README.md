# anilife-dl

thin layer over [anilife.live](https://anilife.live/)

## Usage

```
anime-dl
Usage:
  anime-dl search <query>
  anime-dl list <anime_id>
  anime-dl download <anime_id> <episode_num1>,<episode_num2>,...
  anime-dl download <anime_id> --all
Options:
  -h --help      Show this screen
  -d --download  Download episode of that index
  -a --all          Download all episodes
```
